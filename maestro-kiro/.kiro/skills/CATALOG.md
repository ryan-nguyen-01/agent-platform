# Skill catalog

32 curated how-to skills for **Java/Spring Boot backends + ReactJS frontends + UI libraries**. Each is
a folder with a `SKILL.md`. Load the relevant skill(s) before writing code in that area; start with
`legacy-code-comprehension` to read unfamiliar code.
