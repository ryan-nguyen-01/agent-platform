# Mục lục analysis

> File SỐNG — Kiro cập nhật mỗi khi tạo/sửa một file phân tích. Mỗi module một folder, mỗi tính
> năng một file. Liên hệ giữa các tính năng xem `dependency-map.md`.

| Module | Tính năng | File | Trạng thái | Cập nhật |
| --- | --- | --- | --- | --- |
| <module> | <tính năng> | `<module>/<tinh-nang>.md` | ⏳ chờ xác nhận / ✅ đã chốt / 🔁 cần cập nhật (code đã đổi) | <ngày> |
